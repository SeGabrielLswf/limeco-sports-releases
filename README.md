# LimeCo Admin — releases públicos

Repositorio **solo** para publicar versiones del admin (APK Android y instalador Windows).

- `manifest.json`: lo leen las apps instaladas (Android consulta `android`, Windows consulta `windows`).
- Los binarios van en **[GitHub Releases](https://github.com/SeGabrielLswf/limeco-sports-releases/releases)**, no en el código fuente.

El código del admin vive en el repo privado `limeco-sports`.
